# 📊 Customer Experience & Profitability Dashboard (Tableau)

## 🚀 Project Summary
This interactive Tableau dashboard analyzes sales performance, profitability trends, and regional efficiency to support data-driven business decisions.

The objective of this project was to transform raw transactional data into actionable executive insights using visual analytics and calculated metrics.

---

## 🔎 Business Questions Answered
- Which regions generate the highest revenue?
- Which product categories are most profitable?
- Are discount strategies impacting profitability?
- How does profit margin vary across segments?
- Where are potential performance improvement opportunities?

---

## 📈 Key Metrics Included
- Total Sales
- Total Profit
- Profit Margin (%)
- Regional Sales Performance
- Category-Level Profitability
- Geographic Sales Distribution
- Discount vs Profit Correlation Analysis

---

## 🧠 Analytical Techniques Used
- Calculated Fields (Profit Margin)
- Trend Analysis
- Scatter Plot Correlation
- Geographic Mapping
- Top-N Analysis
- Interactive Dashboard Filters

---

## 🛠 Tools & Skills Demonstrated
- Tableau Public
- Data Visualization
- Business Intelligence Design
- KPI Development
- Data Storytelling
- Interactive Dashboard Design
